# Análisis comparativo de Quick Sort y Merge Sort

## Descripción
Proyecto académico de la Unidad 01 orientado al análisis comparativo de los algoritmos de ordenamiento Quick Sort y Merge Sort mediante un experimento implementado en C++[cite: 5].

## Objetivo
Comparar el rendimiento de ambos algoritmos considerando diferentes tamaños y patrones de entrada, utilizando métricas de tiempo de ejecución y operaciones internas.

## Tecnologías utilizadas
* C++ (Librería estándar `<iostream>`)
* Dev-C++ / Compilador C++
* LaTeX / Overleaf
* Git y GitHub

## Estructura del Repositorio
El repositorio se encuentra organizado bajo los estándares académicos exigidos:
* **`src/`**: Contiene los códigos fuentes modulares de los algoritmos (`quicksort.cpp`, `mergesort.cpp`) con entrada manual[cite: 8].
* **`data/`**: Almacena los conjuntos de datos experimentales y archivos `.csv`[cite: 8].
* **`Docs/`**: Incluye el código fuente en LaTeX (`main.tex`) y el artículo científico compilado en formato PDF[cite: 5, 8].
* **`results/`**: Contiene las gráficas y capturas de los resultados experimentales[cite: 8].
