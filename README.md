# Análisis comparativo de Quick Sort y Merge Sort

## Descripción

Proyecto académico de la Unidad 01 orientado al análisis comparativo de los algoritmos de ordenamiento Quick Sort y Merge Sort mediante un experimento implementado en C++.

## Objetivo

Comparar el rendimiento de ambos algoritmos considerando diferentes tamaños y patrones de entrada, utilizando métricas de tiempo de ejecución y operaciones internas.
